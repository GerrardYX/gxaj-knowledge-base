# 知识库文件目录

## 📂 使用方法（超简单！）

### 1. 放入知识库文件
将你的 Word/PDF/Markdown 文件直接放入本目录：
```
assets/knowledge_files/
├── 产品手册.docx
├── 常见问题.docx
├── 使用指南.pdf
└── README.md (本文件)
```

### 2. 重新打包
```bash
# Windows 版本
npm run build:win

# macOS 版本
npm run build:mac
```

### 3. 分发安装包
将生成的安装包发给客户：
- Windows: `dist/gxaj知识库 Setup 1.0.0.exe`
- macOS: `dist/gxaj知识库-1.0.0.dmg`

### 4. 客户使用
客户安装后：
- **首次启动**时，应用会自动解析 `knowledge_files/` 中的文档
- 解析完成后，客户可以直接提问
- 后续启动无需重新解析（已缓存）

---

## 📋 支持的文件格式
- ✅ .docx (Word 文档)
- ✅ .pdf (PDF 文件)
- ✅ .md / .markdown (Markdown 文档)
- ✅ .txt (纯文本)

## ⚠️ 注意事项

1. **首次启动等待**：客户首次启动时需要等待 1-3 分钟（解析文档 + 计算向量）
   - 建议提前在客户电脑上先启动一次，完成解析
   
2. **文件命名**：避免使用特殊字符（如 `/ \ : * ? " < > |`）

3. **文件大小**：单个文件建议 < 10MB，否则解析会很慢

4. **更新频率**：无需每次小改动都重新打包，可以让客户：
   - 自己上传新文档（如果给管理员权限）
   - 或者你远程发送新文档，让客户手动上传

## 🔧 高级用法

### 强制重新解析
如果修改了 `knowledge_files/` 中的文件，想让客户重新解析：
1. 客户启动应用
2. 按 F12 打开开发者工具
3. 在控制台输入：
```javascript
localStorage.removeItem('gxaj_documents');
location.reload();
```
4. 应用会重新解析所有文档

### 查看解析进度
应用启动时会显示解析进度：
```
📖 正在解析文件: 产品手册.docx
🔢 正在计算文档向量 (5/20)...
✅ 知识库加载完成（3 个文档）
```
