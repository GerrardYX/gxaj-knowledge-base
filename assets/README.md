# 知识库预打包目录

## 使用说明

### 1. 导出知识库（管理员操作）

1. 启动应用，使用**管理员账号**登录
2. 点击左侧 "📚 知识库管理"
3. 上传所有知识库文档（Word/PDF/TXT）
4. 等待所有文档解析和向量计算完成
5. 点击面板顶部的 "📦 导出" 按钮
6. 下载生成的 `gxaj_knowledge_base_YYYY-MM-DD.json` 文件

### 2. 预打包知识库（技术人员操作）

1. 将下载的 JSON 文件重命名为 `knowledge_base.json`
2. 放入本目录 (`assets/knowledge_base.json`)
3. 重新构建安装包：
   - Windows: `npm run build:win`
   - macOS: `npm run build:mac`
4. 新的安装包已包含最新知识库

### 3. 分发安装包（给客户）

- 客户安装后，**首次启动会自动加载**预打包的知识库
- 客户无需手动上传文档
- 客户可以直接开始提问

## 文件格式

`knowledge_base.json` 格式：
```json
{
  "version": "1.0",
  "exportDate": "2026-05-11T09:30:00.000Z",
  "documentCount": 5,
  "documents": [
    {
      "id": 1234567890.123,
      "name": "产品手册.docx",
      "content": "文档完整内容...",
      "size": 12345,
      "uploadedAt": "2026-05-11T09:00:00.000Z",
      "chunkCount": 15,
      "chunks": [
        {
          "text": "文档片段1...",
          "embedding": [0.123, 0.456, ...]  // 384维向量
        }
      ]
    }
  ]
}
```

## 注意事项

1. **文件大小**：`knowledge_base.json` 可能很大（embedding 数据），请耐心等待导出
2. **版本管理**：建议保留历史版本，方便回滚
3. **更新频率**：无需每次小改动都重新打包，建议每月或每季度更新一次
4. **客户自定义**：如果客户需要添加自己的文档，仍可以使用"知识库管理"上传（会追加到预打包知识库）

## 故障排查

### 客户安装后，知识库为空？

- 检查 `assets/knowledge_base.json` 是否存在
- 检查 JSON 格式是否正确（可以用 JSON 校验工具）
- 查看浏览器控制台（F12），看是否有加载错误

### 导出时浏览器卡死？

- 文档太多或太大，导致浏览器内存不足
- 建议分批导出（每次不超过 10 个文档）
- 或升级客户电脑内存（推荐 8GB 以上）

### 重新打包后，安装包太大？

- `knowledge_base.json` 可能很大（embedding 数据是 Float32Array，JSON 序列化后更大）
- 可以考虑：
  1. 压缩 JSON 文件（使用 gzip）
  2. 只打包核心文档，其他让客户自行上传
  3. 使用在线同步功能（需要服务器支持）
